# CloudShield

CloudShield is an AI-powered cloud change risk assistant that helps understand the impact of a cloud change before deployment.

It uses **BigQuery** for change, resource, dependency and incident data, and **Vertex AI / Gemini** for risk explanation and recommendations.

### Main Features
- Risk Assessment
- Historical Incident Analysis
- Blast Radius
- What-If Simulator
- Change Gate
- Evidence Trail

### Tech Used
React • Node.js • Google BigQuery • Vertex AI/Gemini • Cloud Run
